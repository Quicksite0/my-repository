A resource monitor for Windows 11 made in python. Has support for all major GPUs! (need tester for ARC graphics card)

Install (to run off python):
psutil 7.2.2 https://pypi.org/project/psutil/
GPUtil 1.4.0 https://pypi.org/project/GPUtil/
USE Python 3.14.10 or earlier  https://www.python.org/downloads/release/python-31410/
