A resource monitor for Windows 11 made in python. Only has support for NVIDIA GPUs at the moment.

Install (to run off python):
psutil 7.2.2 https://pypi.org/project/psutil/
GPUtil 1.4.0 https://pypi.org/project/GPUtil/
USE Python or later 3.14.10 https://www.python.org/downloads/release/python-31410/
